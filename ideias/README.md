# Banco de Ideias — Primeira Rodada

## Matriz de pontuação (1 a 5, quanto maior melhor)

| Critério | O que significa |
|---|---|
| Velocidade | Quão rápido entra o 1º real |
| Capital | Quanto menos dinheiro precisa, maior a nota |
| Demanda | Existe gente pagando por isso hoje |
| Margem | Quanto sobra de cada venda |
| Encaixe | Combina com o perfil do Paulo (a confirmar em `perfil/paulo.md`) |
| Escala | Dá para crescer sem o Paulo trabalhar proporcionalmente mais |

> A coluna **Encaixe** ainda está como "?" porque depende do perfil do Paulo.

## Leitura rápida do assessor

- **Para dinheiro rápido com pouco capital:** #4 (serviço local) ou #3 (revenda).
- **Para renda recorrente:** #1, #2 e #7 — vender mensalidade para comércio local. É onde eu (Claude) mais consigo trabalhar *junto* com você: eu produzo, você vende e entrega.
- **Para longo prazo/escala:** #5, mas é o mais lento para o 1º real.

Recomendação provisória: **combinar #1 + #7** — "Pacote de presença digital para negócios do bairro" (ver `planos/plano-30-dias.md`). A decisão final depende do seu perfil.

# Assessoria de Negócios do Paulo

Repositório onde o Claude trabalha como assessor de negócios do Paulo, com uma equipe de agentes especializados.

- `CLAUDE.md` — o prompt de trabalho do assessor (carregado automaticamente).
- `.claude/agents/` — os "funcionários": pesquisador, financeiro, copywriter, vendedor, advogado do diabo.
- `perfil/paulo.md` — perfil do Paulo (**preencha primeiro!**).
- `ideias/` — banco de ideias pontuadas.
- `planos/` — planos de ação.
- `diario/decisoes.md` — histórico de decisões e resultados.

Como usar: abra uma sessão do Claude Code neste repositório e peça, por exemplo:
"Pesquise a demanda da ideia #4 na minha cidade" ou "Monte o script de venda para barbearias".
